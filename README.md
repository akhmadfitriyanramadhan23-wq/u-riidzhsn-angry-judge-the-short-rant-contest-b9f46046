# Angry Judge: The Short Rant Contest

Entry for the [Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) on make.fun. A short, furious rant about one small everyday annoyance — an office printer that has exactly one job and still manages to fail at it — escalating from a jammed blank page to 47 unwanted test pages, and ending with the printer's new outdoor address.

> Our printer has one job. Print the page. It jammed on a blank page. There was nothing on the page to jam. IT called it user error. I was in the kitchen. It has printed 47 test pages this week. I asked for none of them. Now it prints one every time I walk past, like a dog barking at its own reflection. I named it Kevin. Kevin is moving outside. In the rain. Forever.

## How to run

Requires Node 22 or later. From this directory:

```sh
node main.ts
```

This writes the rant (367 characters) to `/output/entry.txt`.
